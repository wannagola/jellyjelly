사진은 어디에 들어가나

병 안의 젤리가 SVG인 건 사진을 못 구해서가 아니라 일부러 그런 것입니다. 자리마다 들어가는 게 다릅니다.

젤리 모양 여섯 가지

사진이 없어도 빈 카드가 생기지 않도록, 등록할 때 모양과 색을 고르면 이 SVG가 젤리의 얼굴이 됩니다.
